# TP : nombres, flottants et méthodes numériques

Ce dossier contient les solutions Python des TP du module. L'objectif est de montrer la compréhension des notions de base vues en cours : entiers, flottants, boucles, fonctions, arithmétique, polynômes, matrices, cryptographie et géométrie.

## Fichiers

- `tp1_nombres_flottants.py`
- `tp2_arithmetique_nombres_premiers.py`
- `tp3_polynomes_fonctions.py`
- `tp4_matrices_systemes_lineaires.py`
- `tp5_chiffrement_affine.py`
- `tp6_geometrie_plan.py`

## Objectif pédagogique

Les exercices visent à :
- comprendre la différence entre entiers et flottants,
- mesurer les erreurs d'arrondi,
- manipuler les boucles et les fonctions,
- étudier la divisibilité, le PGCD, la primalité et les clés modulaires,
- représenter des polynômes, des matrices et des objets géométriques,
- évaluer, dériver, résoudre, chiffrer, déchiffrer et interpréter,
- comprendre les principes de la géométrie algorithmique dans le plan.
